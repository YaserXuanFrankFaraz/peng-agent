## Features

- **Session goals — `/goal` (preview)** — Give a session a persistent objective and let the agent keep driving toward it on its own. `/goal <objective>` sets the goal (with `clear`, `edit`, `pause`, and `resume` subcommands); while the goal is active, the agent automatically starts a new turn whenever the session goes idle, and each continuation shows up in the chat as a compact, expandable system capsule so the history stays auditable. Goals support an optional token budget with live usage accounting — once the budget is exhausted the agent is instructed to wind down and report instead of starting new work. The model gets three tools (`get_goal`, `create_goal`, `update_goal`) with strict completion/blocked auditing rules, available on both Claude Code and Pi/Codex sessions, and a goal status panel shows the objective, status, and usage at a glance. Preview: available behind the `sessionGoals` feature flag.

## Improvements

- Floating overlays under custom skins now use a translucent glass treatment (50% surface color with a 10px blur) instead of fully opaque backgrounds, and inline file/Git previews in the chat area pick up a matching frosted look at 90% surface opacity.

## Bug Fixes

- With a custom skin active, the composer's @-mention and slash-command menus are no longer invisible.
- Fixed ghosting in inline file/Git previews and invisible terminal text in light themes when a skin is enabled, and resolved a markdown-rendering conflict with theme colors.
- Inline previews in the chat area now render their glass effect via a reverse-frost technique, working around WKWebView's lack of support for nested `backdrop-filter`.

## Breaking Changes

- None. All changes are backward-compatible.
