## Features

- **Smart Snapshot — one hotkey grabs the app in front of you** — press both of the same modifier key at once (⌘+⌘ on macOS, Ctrl+Ctrl on Windows; ⌥/⇧ variants available) and YuuMira captures the frontmost window of whatever other app you were looking at, then drops both a screenshot **and** the window's full text into your focused session's composer — creating a session if none is open. The text pass reads the whole window through the accessibility layer, including content scrolled off-screen, which is exactly the part a screenshot can't give you. Available on **macOS and Windows**; macOS asks once for Accessibility and Screen Recording permission, Windows needs none at all. Text attachments in the composer can now be **double-clicked to preview** — a wide scrollable panel with a wrap toggle in the corner (wrapped by default; switch it off for table-shaped text you want to keep aligned). **Off by default** — turn it on in Settings → Tools → Smart Snapshot.

## Improvements

- Sitting still no longer keeps old sessions in memory. Session eviction previously only ran when you switched sessions, so parking on one session left the retained set (and any session that had finished working in the background) resident indefinitely. An idle sweep now clears the whole retained set after 5 minutes of no switching; the selected session, split-view panes, and anything still busy are never touched, and revisiting a cleared session restores it from disk in full.

## Bug Fixes

- **Windows appeared to flash black when resizing or reopening a window.** The strip revealed during a live resize — and the first frame after closing and reopening a window — rendered as solid black, because the compositor has no content to draw there. Windows are now created with the theme's own background colour and stay hidden until their first load finishes (with a timeout fallback), and the window backdrop follows the **app's** theme rather than the system's, so a light-themed app on a dark-mode Mac no longer shows a dark strip.
- **Knowledge (QMD) falsely warned that vectors were out of date.** Upgrading the app without touching any data could raise a "vectors are stale" banner and force a full re-embed — one to two hours of wasted CPU on machines without GPU acceleration. Staleness was inferred entirely from config files; it is now settled by reading the actual per-chunk provenance recorded in the index, and a state file that had already been mislabelled heals itself.
- Custom skins: the follow-up island and the file-preview comment popover were the last floating surfaces still mixing their own translucency instead of using the shared glass recipe, so body text showed through them at roughly 37% opacity. Labels on red destructive buttons were washed out for the same class of reason — the text colour tracked the panel-opacity slider, painting white at 20% alpha over solid red.

## Breaking Changes

- None. All changes are backward-compatible.
