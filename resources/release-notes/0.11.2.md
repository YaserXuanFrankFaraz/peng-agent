## Features

- **Smart Workflows** — design and run AI-powered workflows end to end:
  - Guided design sessions: describe what you want and the workflow designer interrogates requirements, then produces a validated workflow spec ready to run
  - Workflow runs dashboard with staged progress, per-run detail pages, and Insights integration
  - Scheduled and recurring runs with automatic recovery after app restarts
  - Run results delivered via Lark messages and Web Push notifications
- Workflow and knowledge-base prompts now follow the UI language (Chinese/English)
