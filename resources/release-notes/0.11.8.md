## Features

- **Semantic search for your knowledge base (preview)** — Settings → Knowledge gains a QMD engine section that indexes your Obsidian vaults with local embeddings, so the app's search and the wiki skills can find pages by meaning instead of exact wording. The engine installs into a YuuMira-managed location using the bundled bun runtime (no separate Node.js install), downloads its embedding model on demand, and keeps model and index caches next to the install so uninstalling reclaims the space. Install, embed, and rebuild run as background jobs whose progress survives closing and reopening Settings. An **index report** dialog shows per-collection document counts, gaps, model status, and maintenance actions, and model files are integrity-checked and repairable in place. Installation can also be handed to the agent: the install button opens a session that performs the install and fixes problems (registry mirrors, hijacked environment variables, layout verification) as it goes. Available on macOS, Linux, and Windows. **Off by default** — enable it in Settings → Knowledge. Full guide: `docs/user_manual/qmd-semantic-search.md`.

- **Traditional Chinese — 繁體中文（香港）and 繁體中文（台灣）** — two new UI languages, generated from the official OpenCC dictionaries and verified against a real OpenCC oracle, with region-specific wording (設定/預設/伺服器/登入 for Hong Kong, 資料來源/透過 for Taiwan). Pick them in Settings → Appearance.

- **Claude Opus 5** — registered as the flagship Opus model and the new default, with Bedrock aliases, fast-mode gating, and pricing wired into usage accounting. Opus 4.8 moves to "previous".

- **Pause a Loop run, steer it by hand, and feed that back into the spec** — running Loops gain **Pause** (stop at the next stage boundary) and **Pause now** (stop the current attempt but keep the sub-agent session). Neither is terminal — nothing already finished is re-run. While paused you can type guidance ("use bun, not npm") and resume; the note is injected into the sub-agent prompt for the rest of the run, and resuming after a "Pause now" continues the same session instead of starting over. Approving a checkpoint can carry a note and optionally pause afterwards. Every intervention lands in a timeline that also feeds workflow refinement, so corrections you keep repeating by hand can become part of the spec.

- **`create_task` tool** — the agent can capture follow-up work as an unstarted Task on the board (ported from upstream v0.11.2).

- **Send a session to another local workspace** — session transfer is no longer remote-only; the Send to Workspace dialog now lists local workspaces alongside remote ones.

## Improvements

- Literal knowledge search runs on ripgrep once a vault is large enough to benefit (~300 pages), and stays on the in-process scan below that, where spawning `rg` is measurably slower. Knowledge task prompts now tell agents to prefer `rg` over `grep`.
- Long-lived windows hold on to much less memory: messages of inactive sessions are unloaded under an LRU and byte budget (busy, visible, and split-view sessions are never touched, and everything is restored on return), and a large per-attachment field that nothing ever read is no longer kept in memory or written into session files. On by default, with a kill switch.
- The workflows list shows a live run badge on cards with an active run that jumps to the run detail page, and a project picker lets you list and start workflows against a chosen project instead of only the current session's directory.
- Insights: a turn's elapsed time no longer includes the stretch where the run was paused waiting for you — a plan left overnight reported 205m; it now reports the ~11m actually spent working.
- Images returned by tools (browser automation, `read`, web fetch) are compressed before entering the conversation, and re-encoding preserves orientation and RGB color profiles while stripping EXIF/GPS/XMP metadata.
- The terminal dock, popovers, dialogs, and dropdowns now share one glass recipe under custom skins, so floating surfaces match the panels beneath them.
- Dialog scrims lightened from 50% black to a 12% wash, so wallpaper and text behind a dialog stay readable.
- The branch picker has a refresh button that runs `git fetch` and reloads branches and stashes.
- Relative links in the enhanced markdown view open as new preview tabs, resolved against the previewed document's own directory (Windows drive and UNC paths included).
- Pressing ↑ in an empty composer recalls your previous prompt.
- A background task that goes quiet for 20 minutes now reports an unknown state instead of spinning indefinitely.
- The Windows installer bundles the Microsoft Visual C++ runtime, fixing document-conversion crashes caused by a missing `MSVCP140.dll`. Machines that already have it are skipped, so updates stay silent.
- The bash tool applies a 120-second default timeout when the model doesn't pass one, matching the Claude engine.

## Bug Fixes

- **Large screenshots no longer poison a session on Codex.** A ~5MB request was rejected at connect time and blindly replayed roughly two dozen times over ~16 minutes, and because the images stayed in session history every later turn failed the same way. Attachments are now compressed on the way in, each request is held to a transport budget that older images are dropped from (the newest attachment is never degraded), oversized-request failures are classified as non-retryable and short-circuited, and a session that hit one automatically sheds image history on its next send — poisoned sessions recover by themselves.
- Insights under-counted usage in long sessions — one session reported 725.6K against an actual 968.4K, because concurrent usage updates overwrote one another instead of accumulating.
- macOS: closing an extra window now actually releases its web content process, which previously stayed resident at 200–400MB each for the life of the app.
- The Settings navigation list couldn't be scrolled to the bottom, leaving "Preferences" unreachable.
- The parent session row now shows as running while a Loop or sub-agent works in a hidden child session.
- Session goals: a session that exhausted its token budget and ignored the wind-down instruction is now hard-stopped after one wrap-up call, instead of running on past the budget.
- Loop Designer: refining a workflow no longer flattens its body and collapses the run view into a single phase card, and `{version}`-style placeholders in done-criteria commands are substituted before the command runs.
- A message queued while the agent was working no longer tells the model that its own completed reply was interrupted, and now replays after that reply instead of ahead of it.
- Knowledge (QMD): turning semantic search off and back on left it silently broken (collections deregistered, skills falling back to grep); the embedding-model choice was silently ignored because the engine's own config file outranked the environment; changing the model never triggered a re-embed and then failed on a dimension mismatch; embedding timed out after 15 minutes on jobs that legitimately need one to two hours; long installs exceeded the 30-second request timeout even though they succeeded; the model cache ignored `XDG_CACHE_HOME`, so "delete downloaded models" removed nothing; renaming the vault `.env` fence produced duplicate blocks and false warnings on already-configured vaults; and several parsers were fixed against real engine output — a fresh install indexed nothing, automatic refresh never embedded, and semantic hits pointed at file paths that didn't exist.
- Windows: deleting a data source (and edits to skills, statuses, and automations) didn't refresh the app, because the native file watcher reported extended-length paths that never matched the watch registry. Sessions could also freeze permanently when the bash tool fell through to the WSL launcher in System32 — that fallback is now refused outright.
- Windows: frosted glass never rendered on any floating surface. The build was collapsing paired declarations down to the WebKit-only form, which Blink ignores; both forms now survive, and the platform-specific opacity workaround has been removed.
- Windows: QMD reported "install failed" after an install that had actually succeeded, and managed installs could land outside the configured location entirely when machine-level `BUN_INSTALL_*` variables redirected them.
- Custom skins: terminal selections turned near-black and swallowed dark text, pasted text rendered as a black block, and labels on inverted buttons became unreadable once panel opacity was turned down.

## Breaking Changes

- None. All changes are backward-compatible.
