## Features

- **Computer Use (experimental)** — let the agent see and control your screen, mouse, and keyboard for tasks that need a real desktop. Disabled by default; turn it on in Settings, which guides you through granting the required system permissions (Accessibility and Screen Recording on macOS). Available across agent engines, with risky actions gated behind confirmation prompts.
- New shortcut: maximize/restore the terminal panel with Shift+Esc (rebindable in Settings → Shortcuts)

## Improvements

- New "About YuuMira" entry in the app menu, with version info, open-source attribution, and a third-party software list

## Breaking Changes

- **The app is now YuuMira** — rebranded from "Craft Agents" for trademark compliance (YuuMira is an independent fork and is not affiliated with Craft Docs Ltd.). What this means when updating from an older version:
  - New app icon and name; the bundle identifier changed to `app.yuuone.yuumira`. Your sessions, workspaces, and credentials in `~/.craft-agent` are untouched. In-app preferences (shortcut overrides, board layouts) are migrated automatically on first launch.
  - macOS: the updater replaces the app in place, so the file in /Applications may still be named "Craft Agents.app" — rename it manually or reinstall from the new DMG if you prefer.
  - Windows: "Craft Agents" may remain listed in Apps & Features after updating — uninstall the old entry manually.
  - Linux: the package is now `yuu-mira`; remove the old `craft-agents` package manually.
  - Old `craftagents://` deep links keep working; new links use `yuumira://`.
