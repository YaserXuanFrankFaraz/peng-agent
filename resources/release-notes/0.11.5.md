## Features

- **Sign in to xAI Grok with your subscription** — a new connection option on the onboarding screen and in Settings signs you in to Grok through a browser-based OAuth device-code login, so SuperGrok and X Premium+ subscribers can use Grok models without pasting an API key. Grok 4.5 pricing is included in usage accounting.

- **X Search** — a new entry in the composer's "+" menu lets the agent search X (Twitter) and cite what it finds. Search runs server-side on xAI's infrastructure with Grok 4.5, works across agent engines, and requires an xAI Grok connection.

- **Image generation** — another "+" menu entry gives the agent an `image_generation` tool for creating images from a prompt and editing images you attach, backed by OpenAI's `gpt-image` models. Works across agent engines and requires a connected ChatGPT subscription or OpenAI API key.

- **Git history in the changes sidebar** — browse the current branch's commit history, switch branches from the sidebar, and open a full diff for any commit. History and diffs are read natively for fast scanning on large repositories.

- **Export a full-page screenshot from full-screen preview** — alongside "Export PDF", full-screen markdown preview can now export the whole document as a single tall PNG. The built-in browser gained matching "Copy full-page screenshot" support on Windows.

## Improvements

- Redesigned two-tier toolbar for the Git changes sidebar, with tighter file and history scanning.
- Desktop notification settings now detect when the system has notifications turned off for the app and offer a fix-it shortcut to the right system pane.
- Per-turn duration in the trace view is measured from when you send the message, so long turns no longer collapse to milliseconds.

## Bug Fixes

- **Fixed high idle CPU on macOS** — every unclicked notification left a thread spinning, burning a full core. Notification handling was moved to the system framework and the click wait no longer busy-waits.
- **Kimi WebBridge browser automation is reliable again** — slow-but-successful commands are no longer killed by a 2-second read timeout, large responses parse correctly, and the daemon can install itself on first use. Screenshots are passed straight to vision models.
- **Fixed Pi connection-error retry storms** — two retry layers were fighting each other and replaying phantom follow-up turns.
- **Fixed diff line-number backgrounds showing through** — code no longer slides under the gutter when scrolling a diff horizontally, and the Git changes preview scrolls properly again.
- The processing indicator keeps its token count moving during thinking and tool calls instead of freezing.
- Fixed the empty-session wordmark animation and spacing on Windows.

## Breaking Changes

- None. All changes are backward-compatible.
