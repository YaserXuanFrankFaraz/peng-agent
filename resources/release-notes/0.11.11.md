## Features

- **A virtual keyboard for launching things — press `⌘R` / `Ctrl+R`.** An overlay drops down a US QWERTY keyboard, and every letter and digit can be bound to one of four actions: launch an application, run a script or a command line, open a folder, or open a URL. Bound keys show the real operating-system icon for their target. Configuration lives inside the panel: type or pick a target and it classifies itself (you can override from a dropdown), and a searchable list of your installed applications shows each one's icon and localised name. Bindings exist at two levels — global, or scoped to the current workspace, where a workspace binding shadows the global one and is marked with an accent dot. Scripts run in a built-in terminal tab so they inherit your login shell's full environment and `PATH`; you can also send them to the system terminal instead (Terminal on macOS, PowerShell on Windows). Application bindings can carry launch arguments. You can keep up to nine keyboard pages and move between them with `‹ ›`, the arrow keys, or `Ctrl+Tab` / `Ctrl+Shift+Tab`, and a switch in the configuration header decides whether key names are printed under each key.
- **Alibaba Cloud Model Studio (DashScope) is now a provider preset.** Both the mainland (`dashscope.aliyuncs.com`) and international (Singapore) endpoints are selectable when you add a custom API connection, and either one pre-fills a sensible Qwen model list (`qwen3-coder-plus`, `qwen3-max`, `qwen-flash`) instead of the default Claude ids.
- **The usage panel now shows whether the AI services themselves are up.** A row of status dots for Claude, OpenAI and DeepSeek arrives with your quota numbers (cached for two minutes, fetched in parallel); click one to open that provider's own status page. Degraded and maintenance states are amber, an outage is red, and a probe that simply cannot reach a source stays a neutral grey rather than claiming something is broken. Ongoing incidents show their title on hover.
- **Sessions can archive themselves.** A new `archive_session` tool lets the model file a finished session away. It is confined to the current workspace, refuses to run mid-turn, and cannot archive the session it is running in.
- **The composer takes focus again when you come back to the app.** Switch to a browser to check something, click back into the window, and the cursor lands in the message box. It deliberately does not steal focus from a text field you were already typing in, from a terminal, or from an open dialog or menu.
- **`browser_tool` can now read what a page logged while it was loading.** The console hook used to be installed the first time you asked for logs, by which point everything from page load was already gone. It is now injected before the page's own scripts run — for the built-in browser and for your real Chrome through WebBridge — and it also collects uncaught exceptions and unhandled promise rejections with their stacks. A read returns the most recent 100 entries unless you ask for a different limit.

## Improvements

- **Engine upgrade to Pi SDK 0.83.0.** The provider catalogue can now be refreshed dynamically, and several newer models are supported natively rather than through fork-local definitions: Kimi K3, qwen3.8-max, and Claude Opus 5 (including its Bedrock regions). Cost tracking knows the published rates for all three. Network refresh of the catalogue is off by default, so the upgrade adds no new outbound requests on its own.
- **Signing in with ChatGPT survives OpenAI's refresh-token rotation.** OpenAI hands back a new refresh token on every renewal; the new one is now written back to the credential store, so a long-lived connection no longer expires into a forced re-login.
- **The browser routing capsule tells you when Chrome simply isn't running.** Previously any failure to reach WebBridge was reported as a missing extension. The capsule now checks for a running Chrome first: if there isn't one, it says so and clicking it launches Chrome — the state refreshes on its own when you return to the window. Only a Chrome that is genuinely running falls back to the "install the extension" state.
- **MCP tools whose names contain dots now work.** Names are sanitised on the way through the proxy, and a collision keeps the first tool and warns instead of quietly shadowing one.
- **A new session inherits your currently active filter.** If exactly one include-type filter is active in the session list, opening a new session keeps it, so the session you just created doesn't vanish from the view.
- **The model list refreshes in the background after you re-authenticate** or validate a connection, instead of waiting for the next app start.
- **`CLAUDE_CODE_GIT_BASH_PATH` is passed through on Windows** so tools that need Git Bash find the same one the app resolved.

## Bug Fixes

- **GitHub Copilot on the free plan offered nothing but broken models.** Every entry in the picker failed with `model_not_supported`. Three things were wrong at once: the API's `policy.state === "enabled"` flag was being read as "you can use this", which it is not on that plan; the models the free plan can actually serve — `gpt-4.1` and `gpt-4o` — were being removed by an old `gpt-4` name filter; and the preferred default models were still written with the pre-0.83.0 hyphenated ids, so even title generation failed to resolve a model. The list is now built the way the SDK's own picker builds it, with a free-plan fallback, intersected with the real catalogue so an unresolvable id can never reach the picker. A model that fails to resolve now reports that clearly instead of silently running on the SDK default and blaming a model you never chose. Existing broken configurations repair themselves on the next refresh.
- **On Windows, the keyboard went completely dead after `Alt+Tab`ing back to the app.** Not just some shortcuts — every keystroke, until you clicked inside the window. Returning to the window hands keyboard focus straight to a Chromium child window that the host never hears about, so neither the window manager nor the web layer noticed anything had happened, and the usual focus-forwarding call had no effect on a window in that state. The app now hooks window activation itself and pushes focus directly into the web view's input window, with diagnostics logged at each trigger point and guards that make a focus loop structurally impossible.
- **On Windows, `Ctrl+R` reloaded the whole application** and right-clicking anywhere offered a browser page menu with "Refresh" on it — both inherited from WebView2's built-in accelerators. Browser accelerator keys are now disabled in release builds, and the default page context menu is suppressed outside editable fields, selections and the terminal, so copy, paste and spell-check menus are unaffected.
- **The "comment on selection" popover in file preview was transparent and wouldn't close.** Nested behind the preview panel's own frosted backdrop, its blur was silently dropped and the document text showed straight through it; and because the popover intentionally does not take focus (taking it would collapse your selection and break `⌘C`), the `Escape` key it listened for could essentially never be pressed. It now renders outside the panel so the frosted effect actually works, follows the text as you scroll or resize, and closes on `Escape` or on a click anywhere outside it.
- **A Loop run that hit its token budget could not be resumed.** The engine and the protocol both supported topping the budget up, but nothing in the interface ever sent one — so every resume re-checked the same exhausted budget, paused again immediately, and threw away the manual guidance you had typed along with it. The pause panel now has a top-up field (accepting `500k` and `1M` as well as plain numbers, plus three presets), resuming without one fails with an actionable error instead of spinning, and the added budget is stored so it survives a restart.
- **PowerShell validation was still missing from packaged builds on Windows.** The 0.11.10 fix put the validator script in the server's resources, but the packaged supervisor looks for it under the application resource root, so safe-mode PowerShell commands kept failing there. The script is now packaged in both places, with a byte-level test pinning the copy to its canonical source so the two cannot drift apart.
- **Empty `tool_calls: []` in an OpenAI-compatible stream dropped the chunk it arrived on.** The empty array was read as a tool-call delta, discarding text that came with it. Empty keys are now stripped before forwarding.
- **Chinese, Japanese and Korean input in the message box could be mangled** by the browser's autocapitalise and autocorrect behaviour, which is now turned off for rich-text input.
- **Absolute Windows paths could be joined onto the workspace root a second time**, producing paths like `C:\project\C:\project\file.ts`.
- **A stale server lock could block startup permanently.** If the recorded process id had been reused by an unrelated process — something macOS does routinely — the app treated the lock as live forever. The lock now records the executable name too, so a reused id is recognised as stale.
- **Links containing `%` were not linkified** in rendered markdown.

## Breaking Changes

- **The right sidebar toggle moved from `⌘⇧R` / `Ctrl+Shift+R` to `⌘⇧E` / `Ctrl+Shift+E`.** The old binding was reassigned to the new quick launcher, which has since settled on `⌘R` / `Ctrl+R`. If you had recorded your own shortcut for either action, your override is untouched.
