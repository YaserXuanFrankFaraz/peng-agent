## Features

- **A workflow run can choose which model it runs on.** The Loop start form now has a model dropdown next to the workflow you are launching, so a run can be executed on, say, DeepSeek V4 Flash without touching your application default — leave it alone and the run follows the default connection's default model, exactly as before. The choice is remembered per workflow, so the next launch of that same workflow offers what you picked last time. A stage that pins its own model in its frontmatter still wins over the run-level choice, which in turn wins over the default. The selection is stored with the run, so a restart resumes the remaining stages on the same model, and continuing the conversation from a run's anchor session keeps it too. The run detail page shows the active model beside the status badge. Runs started by the scheduler, or by an older client that doesn't send a model, behave exactly as they did before.
- **The quick launcher answers a system-wide hotkey.** Double-tap `⌘` (`Ctrl` on Windows) from any application and the launcher keyboard drops down over whatever you were doing; tap it again to dismiss. Settings → Application → Tools lets you switch it to `⌃` or `⌥` (`Alt` on Windows), or turn it off entirely. The gesture is deliberately a double *tap* rather than a chord, and a sequence is discarded the moment any other key joins in or both sides of the modifier are held together — so holding `Ctrl` while hammering `C`, or triggering Smart Snapshot on the same modifier, never summons the launcher by accident. On macOS this needs Accessibility permission for presses outside the app (the settings card says so and links straight to the system pane); pressing it while the app is in front works without it. On Windows it needs no permission at all.

## Improvements

- **API key connections are now named after the provider they talk to.** Adding a preset connection produces "DeepSeek (API Key)" instead of a generic default template name. Connections you already have keep their current names — rename them yourself if you want the new form.
- **The launcher keyboard paints complete on the very first summon.** The bindings and their operating-system icons are now warmed at application start, and the navigation signal that a global summon rides on is emitted immediately instead of after a fixed delay, so an already-open window opens the overlay without the visible lag and the empty-keycaps-then-icons-popping-in flash.

## Bug Fixes

- **Testing a DeepSeek connection always failed with a timeout.** The failure had nothing to do with your key, your network or the model id — the connection test runs a real miniature completion inside a 25-second budget, and DeepSeek's reasoning models spend around 90 seconds on internal reasoning before the first token appears, so the test could not do anything but time out. Connections of this type are now verified with a fast `GET /models` probe against the endpoint (about a quarter of a second in practice), falling back to the old path if the provider doesn't answer that route; Groq, Cerebras and OpenRouter benefit from the same change. Note that DeepSeek's reasoning models genuinely are slow to first token in normal conversation — that is the provider's behaviour, and the transport timeout covers it.
- **A misleading "Custom endpoint without protocol config" error accompanied that failure.** The setup wizard was passing a preset's own default URL back as if you had typed a custom endpoint. It now sends nothing when the URL is unchanged from the preset.
- **Re-adding a preset connection left it on the default template name.** The wizard passes the preset key through to the server, which renames the connection using its display-name table — but three presets (`deepseek`, `openai-eu`, `openai-us`) were missing from that table, and a lookup that found nothing skipped the rename silently, leaving the generic name behind.

## Breaking Changes

- None. All changes are backward-compatible. Note that the new global quick-launcher hotkey is **on by default** at double-`⌘` / double-`Ctrl`; set it to "None" in Settings → Application → Tools if you would rather it stayed out of the way.
